## Projects
 
### [OpenAPI Editor & API Client](https://github.com/AlexLalalala/swagger-editor-app)
*RS School · Team project, team lead · 2026*
 
A web app for editing OpenAPI specs in YAML or JSON and sending requests to the endpoints they describe, like Swagger Editor combined with Postman. As team lead I coordinated the team, set up our processes and reviewed code. I personally handled the Supabase integration (Auth, SQL) and the Vercel hosting.
 
`Next.js` `TypeScript` `Supabase` `TanStack Query` `Tailwind CSS`
 
### [REST API backend for an inventory management app](https://github.com/AlexLalalala/ILearning-Final-Project)
*Itransition · Training · 2026*
 
The backend for an app where users create custom items and inventories. I built its core in a few weeks with no prior experience of the stack: JWT authentication (Passport), role-based access control (CASL), TypeORM with PostgreSQL, request validation and Swagger documentation.
 
`NestJS` `PostgreSQL` `TypeORM` `Passport` `CASL` `Swagger`
 
### [Search Trends Dashboard](https://github.com/AleksandrZin/google-election)
*Personal project · 2024*
 
A Dash/Plotly dashboard comparing Google search interest in red and blue US states around the 2024 election, with a two-sample t-test. I scraped the election results with BeautifulSoup, combined them with Google Trends and geographic data in Pandas, and deployed it on PythonAnywhere.
 
`Python` `Dash` `Plotly` `Pandas` `SciPy` `BeautifulSoup`
